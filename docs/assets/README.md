# README screenshots

`wmux-workspace.png` was captured from the running Electron renderer at version
2.51.0, using the shipped UI styles and components. It is not a design mockup or
a composited window image.

The layout shows three agent conversations: two stacked on the left, a browser
beside the upper conversation, a third conversation at full height, and Git on
the right. The browser loads the live English wmux.org page. The Git pane shows
the real commit graph and a selected release commit from a clean local clone of
the public wmux repository.

Terminal transcripts and activity states are staged example data, disclosed in
the main README caption. No private projects, conversations or personal home
directories are included.

- Capture: 2048 × 1220, dark appearance, Dracula terminal theme.
- Inactive-pane dimming is disabled through the appearance preference.

For future captures, use an isolated wmux instance, populate a disposable demo
repository, and capture the renderer after terminal writes have painted. Keep
terminal text readable at the README's displayed width. Check the full image for
personal data, clipped content, transient overlays and stale version references
before replacing the asset.

Other images in this directory, including the earlier Trail demo in
`wmux-git-review.png`, are older captures retained for existing links.
