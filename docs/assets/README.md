# README screenshots

`wmux-workspace.png` and `wmux-git-review.png` were captured from the running
Electron renderer at version 2.51.0, using the shipped UI styles and components.
They are not design mockups or composited window images.

The isolated demo uses a small local repository named Trail. Terminal transcripts
and agent activity are example data, marked as such in the images and main README.
The Git screenshot displays an actual working-tree diff in that demo repository.
No private projects, conversations or personal home directories are included.

- Workspace: 1600 × 900, dark appearance, Dracula terminal theme.
- Git review: 1800 × 900, dark appearance, Dracula terminal theme.

For future captures, use an isolated wmux instance, populate a disposable demo
repository, and capture the renderer after terminal writes have painted. Keep
terminal text readable at the README's displayed width. Check the full image for
personal data, clipped content, transient overlays and stale version references
before replacing either asset.

Other images in this directory are older captures retained for existing links.
