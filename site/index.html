Agents

Bring the agents and accounts you already use. wmux sells none.

Integrated

wmux installs hooks, plugins or instructions so the sidebar knows each agent's state. It asks first.
  • Claude Code Hooks for state and notifications, session resume, hooks inside running WSL distros.
  • Codex Opt-in conversation restore through a launcher, without hooks.
  • OpenCode A plugin and an AGENTS.md block, plus session resume.
  • Qwen Code Hooks, instructions and session resume.
  • Kiro A wmux steering file in your Kiro folder.
  • pi An extension, scoped instructions and session resume.
  • omp Oh My Pi: an extension, an AGENTS.md block and session resume.
  • Grok Build Hooks and a rules file, only when the grok CLI is installed.
  • Antigravity CLI A plugin and conversation resume for agy.

Attention

Ctrl+Shift+A opens the agent navigator, blocked agents first. Desktop notifications fire when work finishes or needs input.

The sidebar shows who works and who waits. One shortcut jumps to the agent waiting for you.

Navigate, snapshot, click and screenshot from the CLI. It also exposes a CDP endpoint for DevTools-protocol clients. It starts blank.

Splits and tabs

Ctrl+D splits right, Ctrl+Shift+D splits down, Ctrl+Shift+Enter zooms a pane. Workspaces group them.

Split, drag tabs between panes, zoom one, save the layout.

Git view

Worktrees

wmux new-workspace --worktree <branch>. When you close the workspace, you choose to keep or discard the checkout.

Restore

Agent conversation resume is opt-in per agent. Running processes do not survive a restart: shells start again.

Layouts, tabs and folders come back. A closed tab reopens with its agent.

FAQ

Is wmux free?
Yes. It is open source under the MIT license, with no account and no paid tier.
Does wmux include an AI model?
No. It runs the command-line agents you already use, with your own accounts.
Does it send any data?
No telemetry or analytics. It checks GitHub for updates, and you can turn that off. Opening the release notes also fetches them from GitHub.
Do my agents keep running after a restart?
No, processes stop. Layouts come back, and agent conversations can resume if you turn it on.
Which Windows versions?
Windows on x64. There is no macOS or Linux build.
Is wmux a fork of cmux?
No. It is an independent Windows implementation inspired by cmux, and reuses none of its code.
